# BiyaheCavite
 
Commute and fare planner for Cavite. Detects your location, lets you tap a drop-off on a real map, gets the road distance (OpenStreetMap routing) and shows estimated fares by mode.
 
## Run it
Open `index.html` on a local server or deploy with GitHub Pages (HTTPS is required for location access).
 
## Notes
- Map: Leaflet + OpenStreetMap tiles. Routing: public OSRM demo server (fair use, fine for testing; use your own router or a paid provider for production).
- Jeepney fares follow LTFRB rates effective Sept 28, 2026. Other modes are estimates.
